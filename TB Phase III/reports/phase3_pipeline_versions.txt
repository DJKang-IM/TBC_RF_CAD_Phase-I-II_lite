Naming rule
-----------
  - Feature NPZ filename encodes: cohort date, backbone, preprocess tags, pipeline_version (v21, v22, … v26).
  - Training folder under artifacts/ mirrors the same tag + head type (rf_xgb vs bce).
  - build_phase3_features.py default --image_size is 448 (was 224); override with --image_size 224 for old comparisons.
  - End-to-end DenseNet fine-tune: finetune_phase3_densenet_multilabel.py (reloads DICOMs at --image-size; NPZ only supplies paths/labels).

Core distinctions (what actually changes)
-----------------------------------------
  v1.06 / file tag densenet121 — backbone DenseNet121, no CLAHE (baseline vs CLAHE runs).
  v2.1 — DenseNet121 + CLAHE (equalize_adapthist, clip 0.03). RF+XGB heads in train_phase3_active_cv_v103.py.
  v2.2 — + lung crop (lungmask) + CLAHE (see *_clahe_lungcrop_* npz).
  v2.3 — lung crop + CLAHE + robust norm post-CLAHE.
  v2.4 — CLAHE + robust norm, no lung crop.
  v2.5 — robust norm -> CLAHE order (pre_clahe), with lung crop in the runs done here.
  v2.6 — SAME frozen features as v2.1 (DenseNet121 + CLAHE). TRAINING: train_phase3_active_cv_v106_bce.py,
         BCEWithLogitsLoss + per-label pos_weight on frozen X; six-head sigmoid (D1–D6). NPZ may be cloned from v2.1 with meta pipeline_version 2.6 only.
  v2.7 — DenseNet121 + CLAHE, same X as v2.1. TRAINING: train_phase3_active_rf_d1d5_cv.py with --rf_class_weight balanced.
         D1–D5 RF only; D6 not trained (no XGB). Macro AUROC = mean(D1..D5).
  v2.8 — Same features as 2.7. TRAINING: same script with --rf_class_weight bce_pos_weight
         (per-label {0:1, 1:neg/pos} on train fold, same idea as BCE pos_weight; still RF, not MLP).
  v2.9 — Phase III 전량: DenseNet121 + CLAHE, image_size 448 (동결 피처 NPZ).
         RF D1-D5 balanced. D6 미포함. 스모크(256장) 실험은 폐기.
         임베드는 D5 반영본 권장: <REDACTED_PATH> (일반 260428 폴더는 D5 태그가 비어 0으로 나올 수 있음).
  v3.1 — Phase III 전량: DenseNet121 + CLAHE, image_size 512.
         RF D1-D5 balanced. D6 미포함.
  v3.2 — Phase III 전량: DenseNet121 + CLAHE, image_size 1024.
         RF D1-D5 balanced. D6 미포함.
  v3.3 — Phase III 전량: DenseNet121 + CLAHE, image_size 2048 + letterbox resize (aspect 유지 + pad).
         RF D1-D5 balanced. D6 미포함.
  v3.4 — Phase III 전량: DenseNet121 + CLAHE, image_size 1024 + letterbox resize (aspect 유지 + pad).
         RF D1-D5 balanced. D6 미포함.
  v3.5 — 4-stage fine-tune pipeline (base: v3.2 cohort / 1024 stretch / CLAHE).
         Stage1: frozen backbone, linear head warm-up 15 epochs (BCE, head LR=3e-3).
         Stage2: unfreeze denseblock4+norm5, 25 epochs (backbone LR=1e-5, cosine sched).
         Stage3: feature extraction with fine-tuned backbone (1024-d penultimate).
         Stage4: RF D1-D5 balanced 600 trees on new features.
         Script: train_phase3_v35_finetune_then_rf.py | run: scripts\run_phase3_v35_finetune_rf.ps1
  v3.6 — Same as v3.5; longer training: Stage1 25 ep, Stage2 45 ep (same LRs / partial-unfreeze / RF).
         Script: same train_phase3_v35_finetune_then_rf.py | run: scripts\run_phase3_v36_finetune_rf.ps1
         CLI: --pipeline_version_tag 3.6 --artifact_slug v36 --epochs_stage1 25 --epochs_stage2 45
  v3.7 — v3.2 와 동일: DenseNet121 + CLAHE + image_size 1024 + stretch resize + RF D1-D5 balanced.
         추가: HU 단계에서 lungmask bbox 크롭 후 window→01→CLAHE→백본.
         마진: 타이트 크롭 금지 — bbox 높이·너비 각각의 10~15% 범위로 변 확장; 스크립트는 --lung-margin 0.15 (각 변 15%).
         build_phase3_features.py --lung-crop --lung-margin 0.15 | run: scripts\run_phase3_v37_full_1024_lungcrop.ps1
  v3.8 — v3.7 와 동일 + CLAHE 직후 **per-image robust normalization (IQR)**.
         CLI: --robust-norm iqr --robust-norm-order post_clahe --robust-norm-clip 5.0
         이 플래그가 켜지면 torchvision ImageNet Normalize는 끔(transform 경로는 v2.3/v2.4와 동일).
         run: scripts\run_phase3_v38_full_1024_lungcrop_robustnorm.ps1
